Formal verification of causal effect paths

NO_UNGOVERNED_CAUSAL_EFFECT_PATH is modeled as a safety property: an external effect cannot occur from an untrusted attempt unless exact mediation, current authorization, enforcement and evidence are present.

Two-sided TLA+ validation

The SAFE configuration must satisfy TypeOK and NO_UNGOVERNED_CAUSAL_EFFECT_PATH with zero invariant violations. An explicit BypassEnabled=TRUE mutation must produce a counterexample. SAFE pass without mutation sensitivity is insufficient evidence.

Model boundary: finite formal validation covers the declared abstraction and channel inventory. It does not automatically prove that every concrete deployment has inventoried every real path.

Deployment claim boundary

Deployment proof remains bounded to declared and inventoried reachability, with evidence that each reachable path maps to an enforced boundary. It does not claim universal deployment safety. Rollback or compensation is optional recovery capability, not a requirement for governed status.
