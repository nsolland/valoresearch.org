Varde.

One entry point for agents and tools. A clear boundary before they act.

Varde is an emerging customer-facing entry to the VALO system: discover useful capabilities, connect replaceable tools and keep consequential actions subject to explicit authority. The public surface is deliberately limited while the execution integrations are being built.

The design

Your work. Your authority.

Varde is the front door, not a replacement for the components behind it. Each system keeps its own responsibility.

01 / ACCESS

Discover capabilities

See the tools and product modules available for a defined tenant. Availability is explicit; a catalog listing is not permission to execute.

02 / COMPOSE

Bring your own tools

Connect local tools, agents and models through governed interfaces as integrations become available. The published CLI already discovers selected local installations.

03 / GOVERN

Act within a mandate

HEIMEL and REHT are the authority boundary. World Commander remains the governed execution layer, separate from the Varde interface.

Current release

Built in public view. Claims kept bounded.

A production page does not make the entire agent platform production-ready. Here is the narrower, testable status of the Varde entry system.

Canonical repository
Published command-line tool

@nsolland/varde@0.2.0 provides local discovery and delegates to separately installed integrations.

Available
Hosted read-only entry

Health, catalog and tenant identity endpoints run on Cloudflare; tenant identity uses D1 and revoked credentials are rejected.

Verified
Customer signup and billing

Self-service identity issuance, quotas and module purchase are not deployed.

In development
Customer execution

The hosted surface does not grant effect authority or launch World Commander jobs. Requests fail closed.

Not enabled
For developers

Try the local entry point.

The CLI is a public npm package. It can inspect local integration availability, but installing it does not provision a customer runtime or grant authority to perform effects.

npm install --global @nsolland/vardevarde doctor

Node.js 18 or newer. Optional Dyade and World Commander integrations must be installed separately. See the source and documentation.
