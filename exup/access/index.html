Bounded EXUP benchmark

Start with one workload and one economic baseline.

The first EXUP engagement is not a platform migration. It is a bounded test that decides whether a verified economic improvement exists.

We agree what may change, what must remain true, and how value will be measured before optimization begins. If the candidate does not pass the acceptance gate, it does not count as savings.

1. Lock the baseline

One real workload: current volume, execution path, cost, latency, reliability and accepted result.

2. Lock the acceptance gate

Quality, task success, latency, reliability, security, resource or hardware constraints that cannot be traded away.

3. Run a bounded benchmark

Only the agreed execution surface is explored. The workload and acceptance contract stay fixed.

4. Verify economic value

Translate an accepted technical improvement into actual provider spend, host-time, hardware BOM, human intervention or another agreed economic metric.

5. Continue only if value exists

If verified value survives, agree production continuation and commercial terms. If not, stop with the evidence.

What you provide

A representative workload, current baseline, acceptance criteria, permitted change boundary and the economic metric that matters.

What you get

A locked benchmark contract, measured candidate comparison, pass/fail decision, claim boundary and economic translation for accepted improvements.

Commercial terms

Benchmark fee: €5k–15k. Credited against the value-share engagement if you continue.

Realization work: typically €10k–50k where customer-environment integration is required.

Verified value share

Standard value share: 20% for 24 months. Continue only if verified value exists and the acceptance gate remains satisfied.

Typical scaling: 25% below €100k annual value, 20% at €100k–€1M, 15% at €1M–€10M; larger cases are negotiated or capped.

Black-box Execution API

Production delivery is available as a private integration using POST /v1/execute. You send the workload, constraints and economic objective; EXUP returns the accepted result, measured metrics, verified savings and receipt. No optimizer internals are returned.

Production runtime

Production runtime starts at €2.5k / month per workload family. Higher-volume production is typically €5k–10k / month; enterprise or multi-workload deployments start at €20k+ / month. The platform fee covers the runtime/control plane; value share remains separate and applies only to verified accepted economic improvement.

Internal optimizer mechanics remain private. The benchmark contract, measured outputs and claim boundary are shared with the participant.
