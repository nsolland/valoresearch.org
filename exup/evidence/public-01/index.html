Public evidence · EXUP-PUBLIC-01

A measurable gain. A fixed acceptance gate.

On a public YOLO11n object-detection workload, the accepted candidate increased SingleStream throughput while reducing latency, with no measured accuracy loss.

+23.2%median throughput · 10 runs
−18.9%median mean latency · 10 runs
−33.5%median p95 latency · 10 runs
Locked test contract

Public inputs. Fixed acceptance boundary.

Workload

YOLO11n object detection on the MLCommons MLPerf COCO safe subset. Accuracy is evaluated across all 1,525 public images.

Scenario

SingleStream CPU inference. Performance comparison uses the same ordered 200-image set for baseline and candidate.

Acceptance gate

Candidate must preserve mAP@0.50:0.95 at or above 0.4000. A faster result that falls below the gate is rejected.

Permitted change

Execution runtime may change. Model task, public input set and acceptance metric remain fixed.

This is a public reproducibility experiment using MLCommons data and evaluation conventions. It is not an official MLPerf submission or MLCommons performance result.

What is disclosed

Enough to verify the result. Not enough to disclose EXUP.

The workload, acceptance gate, measured outputs, model hashes and public result files are disclosed. EXUP's search policy, candidate-generation logic, scoring, heuristics, prompts and next-action logic are not.

Reproducible evidence

Public dataset, fixed model family, fixed evaluation boundary, explicit runtime versions and machine context.

Protected mechanism

The experiment proves that a permitted change was found and accepted. It does not publish how EXUP selected what to test.

Claim boundary

What this result does — and does not — establish.

It establishes a reproducible local CPU result on this locked public workload. It does not establish performance on STM32, Axelera, or any other carrier until the same contract is reproduced there. It also does not claim that every workload will improve by the same amount.
