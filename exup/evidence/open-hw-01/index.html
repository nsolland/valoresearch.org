Commercial memory boundary

Raw envelope crosses an Alif E3 SRAM tier.

Alif documents E3 parts with 3.75 MB and 8.25 MB SRAM. The measured candidate working set is 3,458,304 B, leaving 473,856 B of raw headroom inside 3.75 MiB before runtime stack and application overhead. The baseline working set is 6,393,600 B and therefore requires a tier above 5.75 MB.

Claim boundary

What is proven — and what is not.

Proven: open-toolchain Cortex-M compilation, host execution of the compiler-produced quantized graph, full 1,525-image acceptance, quantized-I/O equivalence, and a raw working-set below 3.75 MiB. Not yet proven: runtime stack/firmware/DMA headroom, physical-silicon latency, energy, or deployable operation on the lower SRAM SKU.
