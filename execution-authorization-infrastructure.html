Execution Authorization Infrastructure

Execution Authorization Infrastructure is the boundary infrastructure that decides whether an exact proposed consequence may become real now and ensures the decision is enforced before effect.

REHT is the VALO product for this layer.

REHT is not an agent manager. It sits at the consequence boundary and resolves current mandate, rights, purpose, constraints, authoritative state and evidence for the proposed action.

VAIG · admissibility and uncertainty
REHT · fresh exact-action authority resolution
RACS · deterministic ALLOW / DENY / ESCALATE contract
Gateway / PEP · effect enforcement
Veritas · receipts and replayable evidence

What this layer is not

It is not IAM, model routing, agent orchestration or observability. Those can contribute identity, capability, process and evidence. Execution Authorization Infrastructure answers the final authorization question for the exact consequential action.
