Onboarding — nytt teammedlem
Følg disse stegene for å legge til Svein, Frank eller andre i dashboardet.
1
Fork eller klon Index-repoet
Teammedlemmet lager sitt eget github.com/[handle]/Index repo med samme struktur.
2
Legg til i TEAM-arrayet
Åpne api/activity.js og uncomment eller legg til: { name: 'Svein', initials: 'ST', color: '#065f46', repo: 'svein-torgersen/Index' }
3
Gjør repoet synlig (public eller token)
Enten sett repoet til public, eller legg til Njål som collaborator slik at GITHUB_TOKEN har lesetilgang.
4
Commit og push
Dashboardet oppdateres automatisk — live data fra GitHub API hvert 2. minutt.
