Deployment surfaces

Surface 01 MCP Sidecar <500ms

A plugin that intercepts LLM tool calls before they execute. Integrates via the Model Context Protocol. No code changes to the agent.

Deploy as

Claude Code plugin MCP server

Appropriate for

  • Claude-native environments (Claude Code, Claude Desktop)
  • Knowledge worker automation — drafting, approvals, summarization
  • Low-stakes production deployments with audit requirements

Gate outputs

ALLOW / DENY with WORM receipt

Surface 02 HTTP Proxy <500ms

A thin reverse proxy between an application and any LLM API. The agent's HTTP requests pass through reht before reaching the model.

Deploy as

ENV: LLM_BASE_URL=https://gate.reht.ai/v1

Appropriate for

  • Any LLM API (OpenAI, Anthropic, Gemini, Mistral)
  • Enterprise environments where agent code cannot be modified
  • Multi-model deployments requiring uniform governance

Gate outputs

ALLOW / DENY with WORM receipt

Surface 03 Agent Loop Gate <100ms

A Python SDK that instruments the agent's reasoning loop directly. EvidenceCondition is checked before intent forms; AARM decides; RRP receipt is issued.

Deploy as

pip install vaig

Appropriate for

  • LangGraph, CrewAI, AutoGen, and custom agent frameworks
  • Workflows requiring stateful Safe Mode (HALT on repeated failures)
  • Deployments where full RRP lifecycle and delegation graph are needed

Gate outputs

Full AARM 6-primitive set (ALLOW / MODIFY / DEFER / DENY / STEP_UP / HALT) + RRP handoff + WHY Gate 4-dimension score

Surface 04 L1 Guardian 43ns

A deterministic 64-byte frame validator written in Rust no_std. Formally verified by TLC model checker: 4,782,943 distinct states, 0 counterexamples. Three checks in order: CRC32C integrity → spread bounds → L4 HALT sentinel.

Deploy as

binary --tcp 127.0.0.1:7743 Docker

Appropriate for

  • Critical infrastructure operators (energy grid, telecom RAN, water supply)
  • Regulated financial execution (trading, credit line dispatch)
  • EU AI Act Annex III high-risk AI system designation
  • Air-gapped and HSM-backed sovereign deployments

Formal properties proven

  • Any CRC corruption → HALT (no silent data mutation)
  • L4 distrust (max_spread = −1.0) → unconditional HALT
  • All paths terminate; no livelock; no deadlock

Standard

VACS conformance across all surfaces

All deployment surfaces emit ACS-compatible packets and receipts. The VACS VALO profile defines authority fields, delegation chain encoding, evidence gap handling, and WORM hash chain format.

VACS conformance package included in Enterprise and Sovereign tiers. The ACS open standard is currently in draft; VALO is the reference implementation.
