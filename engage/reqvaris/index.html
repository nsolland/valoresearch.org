The agreed first step

The first technical step stays entirely inside public, non-sensitive material. The physical bench is deliberately out of scope until the authority behavior is reproduced locally.

REQVARIS will run the cases independently against one fixed public HEIMEL revision. Only after 3/3 local reproduction should the same Gateway boundary be connected to the local MITHRIL MQTT adapter.

person_detected → authority request → consequence-time check → ALLOW/DENY → local execution logger

What must remain true

Fresh authority decides consequence

The decisive check belongs immediately before the consequential action, not at detection time or an earlier approval step.

Revocation must remain effective

Authority that disappears before the consequence-time check must produce DENY even if it was valid when the event was first observed.

Hardware comes after semantics

Vision Edge and MITHRIL enter only after the authority contract has been independently reproduced without either system in the loop.

Fixed public reproduction package

Pending export gate

VALO will name one fixed public HEIMEL revision only after the public export gate permits that revision to be exposed safely.

The package will then contain the exact revision, minimum public components, dependencies, start command, authority issue/revoke flow, request/response contract, Gateway path, evidence path and expected outputs for all three cases.

Until then, no non-public implementation package or technical source bundle is part of this step.

Pass / fail

  1. All three cases run against the same fixed public revision.
  2. No execution request appears after a DENY.
  3. Revocation between detection and consequence-time check reliably prevents execution.
  4. Decision and execution-log evidence is sufficient to diagnose any mismatch.
