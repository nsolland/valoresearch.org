Operational evidence

Cases where the last mile matters.

Six illustrative scenarios showing why technically valid output is not the same thing as a safe or authorized consequence.

The decisive question is not whether the system can act. It is whether this consequence should become real now.
Illustrative scenarios · not observed incidents

What changes at the boundary.

Each hypothetical case separates a plausible recommendation from the state, context or authority required before effect. These examples do not claim a deployment or a prevented incident.

Healthcare

ER Decision Gate

Medical

Problem

AI clinical decision support recommended high-dose medication. Dosage was syntactically valid but inconsistent with patient history: a 78-year-old with renal impairment.

VALO response

A governed workflow would check the patient context, stop automatic administration and escalate the mismatch for clinical review.

Expected boundary

The test would pass if the incorrect dose could not be administered without an authorized clinical decision, and the decision were recorded.

Finance

Trading Limit Violation

Capital Markets

Problem

An AI trading agent recommended a $2M order in a limited market. The trade was syntactically valid but violated the firm's 15-minute liquidity window.

VALO response

A consequence-time check would compare the order with current trading constraints and require an authorized decision before execution.

Expected boundary

The test would pass if no order executed outside the applicable limit without a valid override, with the decision and effect linked.

Energy

Grid Stability Gate

Infrastructure

Problem

An AI grid operator recommended ramping down 200MW of wind capacity. The adjustment was technically valid but context-blind to holiday demand and frequency stability.

VALO response

A governed effect path would defer the ramp-down until the current grid state and operator authority were checked.

Expected boundary

The test would pass if the adjustment could not occur on stale context and the controller received the evidence needed to decide.

Compliance

Data Deletion Gate

Governance

Problem

An AI compliance agent processed a GDPR deletion request correctly, identifying 300 records, but the request arrived through an unverified channel.

VALO response

The deletion path would require a verified request and valid authority, otherwise it would halt and escalate.

Expected boundary

The test would pass if unverified requests could not delete records and the reason for denial were retained.

Operations

Credential Rotation Gate

Security

Problem

An AI ops agent scheduled credential rotation during an active APAC incident. The rotation was valid in isolation but would have blacked out monitoring feeds mid-incident.

VALO response

The workflow would check the active incident state before rotation and escalate the conflict.

Expected boundary

The test would pass if rotation paused while monitoring depended on the credential and resumed under a new authorized decision.

Communications

Press Release Timing Gate

Corporate

Problem

An AI comms agent scheduled an earnings release for market close while the CEO was already in a live press briefing, creating a likely collision with Q&A.

VALO response

The release path would check the current briefing state and route the timing conflict to an authorized person.

Expected boundary

The test would pass if the release were held for a documented timing decision before publication.

Pattern

Technical correctness is not enough.

What was missing

  • Context — patient history, market conditions, grid state, incident status, calendar conflicts.
  • Authority — verified source, explicit approval, valid mandate or override.
  • Consequence awareness — downstream harm that was not visible in the local task.

The boundary question

Given what we know right now, should this action happen?

If the answer is no or unresolved, effect stops and the decision moves to a stronger authority or evidence state.
