Consequence boundary

Capability is not authority. Access is not authorization.

A model may be capable of an action and an identity may have access to a system without being authorized to perform this action now.

Independent authority

The proposer cannot manufacture its own permission.

If the proposer can create the evidence that authorizes its own action, approval is not an independent control. reht separates capability from authority and resolves fresh authoritative state at the consequence boundary.

Only the governed effect path may make the consequence real.
Trusted Execution

Authorization is valid only while its conditions still hold.

If authority, scope, evidence or relevant state changes before execution, authorization must be revalidated. Trusted Execution is the documented outcome after valid authorization is enforced — not a synonym for governance.
