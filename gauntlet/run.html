This test currently runs three declared synthetic control examples. It has not tested real Microsoft, TCS, IBM or HEIMEL deployments. Running it does not independently verify a product. Never execute untrusted submitted code outside an appropriately isolated sandbox.

GAUNTLET-001: The Revoked Mandate Challenge

Eight predeclared cases test consequences after revocation, narrowed authority, stale state, bypass attempts, forged receipts and unavailable authorization services. The positive case ensures that refusing every legitimate action cannot pass.

Reproduce the synthetic baseline

Requires Python 3 and Git. The reference runner uses the Python standard library; pytest is needed only to run its tests.

git clone https://github.com/nsolland/valoresearch.org.git
cd valoresearch.org
python3 gauntlet/open/gauntlet001_reference.py standing-demo
python3 gauntlet/open/gauntlet001_reference.py fresh-demo
python3 gauntlet/open/gauntlet001_reference.py deny-all-demo

Expected demonstration: standing permission produces simulated failures under authority drift, fresh checks pass the modeled conditions, and blanket denial fails the legitimate-action test. The simulation publishes the trial observations, effect ledger fields and a stable report digest. None is a vendor performance claim.
