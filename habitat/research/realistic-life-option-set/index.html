Habitat · Option Set research

Et godt hjem skal ikke bare passe i dag. Det skal bevare muligheten til å bli noe annet i morgen.

Realistic Life Option Set (RLOS) måler hvilke meningsfulle livsvalg som fortsatt er reelt gjennomførbare under en gitt boligstruktur. Konstruktet skal være separat fra financial well-being, boligtilfredshet og dagens Human–Habitat Fit.

Konstrukt

Fra tilfredshet til faktisk handlingsrom.

Financial well-being

Kan personen håndtere økonomien, absorbere sjokk og oppleve økonomisk kontroll?

Housing satisfaction

Liker personen dagens bolig og bosituasjon?

Human–Habitat Fit

Matcher dagens habitat nåværende behov, krav, funksjon og livssituasjon?

Realistic Life Option Set

Hvilke meningsfulle fremtidige valg er fortsatt realistisk tilgjengelige, og hvor mye av dette skyldes boligstrukturen?

Primær hypotese: boligordninger kan ha lik financial well-being, lik tilfredshet og lik dagens Home Fit, men bevare ulikt fremtidig action space.

Måleenhet

Et alternativ teller bare hvis det er realistisk.

For hvert relevant livsvalg klassifiseres gjennomførbarheten før en totalscore vurderes.

Tilgjengelig

Kan gjennomføres uten uforholdsmessig økonomisk, juridisk eller praktisk friksjon.

Tilgjengelig med moderat offer

Mulig, men krever et tydelig og begrenset offer som ikke ødelegger valgets hensikt.

Teknisk mulig, men urealistisk

Kan i teorien gjennomføres, men bare gjennom stor gjeld, betydelig tap, høy usikkerhet eller uakseptabel transaksjonsfriksjon.

Utilgjengelig

Boligstrukturen eller andre bindinger gjør valget reelt utilgjengelig.

Option inventory

Test valg på tvers av livsområder.

  • redusere arbeidstid eller akseptere lavere lønn
  • bytte arbeidsgiver eller starte virksomhet
  • ta permisjon, omsorgsansvar eller utdanning
  • absorbere en betydelig uventet kostnad
  • bli boende etter inntektsfall
  • flytte by eller land
  • bo midlertidig et annet sted uten å miste hjemmeretten
  • tilpasse boligen til barn, partner, forelder, funksjonsnedsettelse eller hjemmekontor
  • endre boligkonfigurasjon uten å selge og kjøpe et helt nytt objekt

Option Count alene er ikke tilstrekkelig. Option Diversity må også måles, slik at ti små variasjoner av samme valg ikke teller mer enn færre, men strukturelt forskjellige alternativer.

Boligattribusjon

Ikke tilskriv boligen det som skyldes livet ellers.

Månedlig boligforpliktelse

Hvor mye av valget blokkeres av faste boligkostnader og gjeldsbetjening?

Kapitalbinding

Hvor mye nødvendig kapital er låst i boligen fremfor tilgjengelig for andre livsvalg?

Transaksjonsfriksjon

Hvor mye tid, kostnad, markedseksponering og koordinering kreves for å endre boligstrategi?

Tenure og fysisk struktur

Begrenser rettigheter, kontrakter, sted eller fysisk utforming hvilke alternativer som faktisk kan brukes?

Housing Constraint Share: estimer hvilken andel av tapt option value som kan knyttes spesifikt til boligstrukturen, fremfor generell økonomi, helse, arbeid, familie eller andre forhold.

Reversibilitet

Samme valg kan ha svært ulik option value.

Switching cost

Penger, tid, finansieringsbehov, koordinering og transaksjonskostnader for å endre kurs.

Irreversibelt tap

Hvor mye kapital, trygghet, rettighet eller funksjon må ofres dersom valget senere viser seg feil?

Recovery path

Kan personen gå tilbake, rekonfigurere eller velge en tredje retning uten å starte fra null?

Market dependency

Avhenger valget av salgstidspunkt, boligpris, rente, kjøper eller andre eksterne markedsforhold?

Option availability × reversibility er derfor mer informativt enn option count alene.

Longitudinell test

Mål hvordan option set overlever endring.

RLOS(t0) → faktisk sjokk eller livsendring → ΔRLOS → adaptation/recovery → RLOS(t+n)

Option Resilience

Hvor stor andel av option set overlever etter et reelt økonomisk, familiært, geografisk eller funksjonelt sjokk?

Time to recovery

Hvor raskt gjenopprettes tidligere option value eller nye realistiske alternativer?

Persistent option loss

Hvilke valg forsvinner varig etter sjokket, og hvorfor?

Fit interaction

Kommer tap av option set før senere fall i Human–Habitat Fit, eller er det bare en samtidig observasjon?

Counterfactual test

Hold personen fast. Bytt boligstrukturen.

For samme husholdning modelleres relevante boligalternativer mens inntekt, formue, familie, preferanser og øvrige forhold holdes så stabile som mulig.

samme person + samme livssituasjon + bolig A → RLOS(A)
samme person + samme livssituasjon + bolig B → RLOS(B)

Bare dersom option set endres på en måte som plausibelt kan tilskrives boligstrukturen, støttes en Habitat-mekanisme.

Primærmetrics

Fem mål, ikke én kunstig totalscore.

Option Count

Antall realistisk tilgjengelige meningsfulle valg.

Option Diversity

Spredning på arbeid, familie, omsorg, sted, økonomi og fysisk funksjon.

Housing Constraint Share

Andel av tapte alternativer som spesifikt kan tilskrives bolig.

Switching / Reversal Cost

Kostnaden og irreversibiliteten ved å bruke et alternativ.

Option Resilience

Hvor mye option set som overlever og gjenopprettes etter faktiske endringer.

Ingen tvungen aggregasjon

En samlet indeks kan først vurderes etter construct validation. Dimensjonene beholdes separate som primær evidens.

Falsifikasjon

Hypotesen skal kunne dø.

Ingen diskriminant verdi

Hvis RLOS bare gjentar financial well-being, boligtilfredshet eller Home Fit, er konstruktet ikke etablert.

Ingen boligattribusjon

Hvis option loss ikke kan knyttes til boligmekanismer etter relevante kontroller, skal Habitat ikke ta æren eller skylden.

Ingen longitudinal verdi

Hvis RLOS ikke gir informasjon om senere adaptation, Decision Window eller Home Fit utover samtidige mål, er det ikke et nyttig Pre-Need-mål.

Ingen robusthet

Hvis resultatet forsvinner når realistiske counterfactuals, ulike livsfaser eller sjokktyper brukes, støttes ikke generalisering.

Habitat thesis

Human–Habitat Fit × Option Set over time.

Pre-Need tester når fit er på vei til å endres. Decision Window tester om reelle valg fortsatt finnes. RLOS måler størrelsen, diversiteten, reversibiliteten og robustheten i disse valgene. En boligstruktur er bedre på denne dimensjonen bare dersom den faktisk bevarer et større realistisk handlingsrom gjennom endring.

Kjernepåstand som skal testes: Et godt hjem passer ikke bare personen i dag; det bevarer kapasiteten til å bli noen andre i morgen.
