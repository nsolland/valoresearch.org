Interpretation rule

Evidence is not inference.

A source record describes the document. Evidence records state only what the source supports at a cited location. Claims state what VALO considers supported. Analysis is explicitly marked as VALO inference. Multiple documents derived from the same primary source belong to one independence family and do not count as independent confirmation.
